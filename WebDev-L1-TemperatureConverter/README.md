# WebDev-L1-TemperatureConverter

## OASIS INFOBYTE — Web Development & Designing — Level 1 — Task 3

### Project
Temperature Converter Website

### Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript

### Features covered
- Numeric input field
- Unit selector for Celsius / Fahrenheit / Kelvin
- Converts to all three output units simultaneously
- Convert button
- Real-time form submission validation
- Absolute-zero edge-case validation
- Clean centered responsive UI

### Test examples
- `0` Celsius → `32 °F` and `273.15 K`
- `100` Celsius → `212 °F` and `373.15 K`
- `32` Fahrenheit → `0 °C` and `273.15 K`
- `273.15` Kelvin → `0 °C` and `32 °F`
- `-300` Celsius → validation error

### Run
Open `index.html` with Live Server in VS Code.
